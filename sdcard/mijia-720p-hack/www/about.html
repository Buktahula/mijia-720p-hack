About Mijia 720p Hack

Modern custom firmware modification for the Xiaomi Mijia 720p 360° Smart Home Camera (Grain Media GM8136S).

Hardware Specifications
SoC Grain Media GM8136S (ARMv5TE @ 400MHz)
RAM 64 MB DDR
Sensor / Video 1.0MP CMOS, 1280x720p @ 25fps H.264
PTZ Motors 360° Horizontal Pan (0..31 steps), 115° Vertical Tilt (0..15 steps) via /dev/motor
Night Vision 850nm IR LEDs (PWM 0..255) + Mechanical IR-Cut filter
Audio Microphone & Internal Speaker
Network 802.11 b/g/n 2.4GHz Wi-Fi (Realtek 8188)
Storage MicroSD Slot (FAT32, mounted at /tmp/sd)
Firmware Features
  • Local RTSP Server: High quality direct H.264 stream at rtsp://<IP>:554/live/ch00_0.
  • Full PTZ Motor Control: Virtual D-Pad, variable step sizes, position presets, calibration, and keyboard navigation.
  • Home Assistant Ready: Direct integration via RTSP and REST API commands.
  • Cloud Free: Eliminates telemetry and dependency on external servers.
  • Services: Dropbear SSH, Telnet, Lighttpd HTTP, FTP, Samba, NTP sync.
  • Video Recordings: In-browser MP4 recording browser and video player.
REST API Reference

All API endpoints accept GET and POST requests and return JSON responses.

/api/motor.php
  • ?action=status — Returns current motor position (HPOS, VPOS, x, y)
  • ?action=move&dir=up|down|left|right&step=1..5 — Move in direction
  • ?action=goto&x=0..31&y=0..15 — Move to absolute coordinates
  • ?action=center — Move to center position (16, 7)
  • ?action=calibrate — Run motor limit calibration sequence
  • ?action=preset&id=1..4 — Move to saved position preset
  • ?action=set_preset&id=1..4 — Save current position to preset
/api/camera.php
  • ?action=status — Returns night mode, IR-cut, IR LED brightness, flip, mirror, LEDs
  • ?action=night_mode&mode=auto|on|off — Set night vision mode
  • ?action=ir_led&value=0..255 — Set IR LED brightness
  • ?action=ir_cut&state=on|off — Switch physical IR-cut filter
  • ?action=flip&state=on|off — Toggle ceiling vertical flip
  • ?action=mirror&state=on|off — Toggle horizontal mirror
  • ?action=led&color=blue|yellow&state=on|off|blink — Control front status LEDs
/api/system.php
  • ?action=info — Returns CPU load, memory, SD card usage, WiFi signal, services
  • ?action=reboot — Safely reboot the camera
  • ?action=service&name=<svc>&cmd=start|stop|restart — Manage services
